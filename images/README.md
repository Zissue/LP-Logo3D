# Screenshots

This directory contains screenshots of the Logo3D programs in action.

## How to Generate Screenshots

To generate screenshots of your Logo3D programs:

1. Run any Logo3D program:
   ```bash
   python3 logo3d.py inputs_tests/espiral.l3d
   ```

2. When the VPython 3D window opens, you can:
   - Rotate, zoom, and position the view to your liking
   - Take a screenshot using your system's screenshot tool
   - Or use VPython's built-in screenshot capability

3. Save screenshots in this directory with descriptive names like:
   - `espiral_3d.png` - The 3D spiral example
   - `cube_3d.png` - The cube drawing
   - `pyramid_3d.png` - The pyramid structure

## Expected Visual Outputs

### Spiral (`espiral.l3d`)
A spring-like 3D structure with multiple circles stacked vertically, each rotated slightly and positioned higher than the previous one. The red cylinders and spheres trace the path of the turtle as it moves through 3D space.

### Cube (`cube.l3d`)
A wireframe cube rendered in cyan color, showing all 12 edges of the cube with clear 3D perspective. The turtle's path creates the outline of a cube visible from multiple angles.

### Pyramid (`pyramid.l3d`)
A golden-colored stepped pyramid with triangular shapes decreasing in size as they stack upward. The structure has a distinct 3D appearance with visible depth.

### Basic Turtle (`turtle.l3d`)
An L-shaped orange path in 3D space, demonstrating how the turtle can move and rotate in three dimensions, creating a simple corner that extends both horizontally and vertically with an upward tilt.

## Note

Screenshots need to be generated by running the programs with VPython installed. Due to the interactive nature of VPython and its dependency on a display environment, screenshots should be captured manually when running the programs in a graphical environment.
